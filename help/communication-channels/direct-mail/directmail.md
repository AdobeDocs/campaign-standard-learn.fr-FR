# Créer un [!UICONTROL publipostage direct] {#create-a-direct-mail}

Le canal [!UICONTROL Publipostage direct] vous permet d’extraire une liste segmentée de destinataires à envoyer à une agence ou à charger sur un serveur SFTP.

Cette vidéo explique comment configurer une diffusion [!UICONTROL publipostage direct] et quels paramètres sont requis pour pouvoir ajouter un profil à une diffusion [!UICONTROL publipostage direct].

>[!VIDEO](https://video.tv.adobe.com/v/23417?learn=on){transcript=true}

## Création d’un [!UICONTROL publipostage direct] dans un workflow

Le canal est disponible à partir de la page d’accueil et dans la vue de workflow afin de définir des stratégies marketing cross-canal cohérentes. L’exemple de workflow suivant inclut l’activité [!UICONTROL  Publipostage direct ].
