# Créer un profil de test {#creating-a-test-profile}

Les profils de test permettent de cibler des destinataires additionnels, qui ne correspondent pas aux critères de ciblage définis. Ils sont ajoutés à l’audience d’un message afin de détecter toute utilisation frauduleuse de votre base de données de destinataires ou de s’assurer que les e-mails arrivent dans les boîtes de réception.
